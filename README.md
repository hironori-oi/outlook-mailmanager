# メール変換ツール（Outlook ドラッグ＆ドロップ用）

Outlook（classic / 新しい Outlook どちらでも）から、メールを**好きなフォルダー**へ
ドラッグ＆ドロップすると、数秒後に選択画面が開き、本文（HTML / TXT）と
添付ファイルに分けて保存できます。元の .eml / .msg は変換後に
**ごみ箱へ移動**されます（万一のときはごみ箱から復元できます）。

対象範囲: 「ドキュメント」と「デスクトップ」配下のすべてのフォルダー
（config.ini の watch_roots で変更できます）

## ドロップすると出る選択画面（ask モード・現在の設定）

- **フォルダーを作成して保存する** … チェックを外すとフォルダーを作らず直接保存
- **フォルダー名** … 初期値は「YYYYMMDD_件名」。自由に書き換え可能
- **添付ファイルを保存する** … チェックを外すと本文だけ保存
- **本文ファイル名** … 自由に書き換え可能
- **本文の形式** … HTML（見た目そのまま）/ テキスト / 両方
- 「変換しない」を押すと何もせずメールファイルをそのまま残します

毎回聞かれるのが煩わしくなったら、config.ini の `mode = ask` を `mode = auto` に
変えると、下記の設定どおり黙って変換するようになります。

## 保存のされ方

**folder スタイル**（フォルダー作成あり）:

```
20260807_会議資料の送付/
 ├─ mail.html        ← 本文（ダブルクリックでブラウザ表示）
 ├─ attachments/     ← 添付ファイル（PDF や Excel をそのまま開ける）
 └─ assets/          ← 本文内の画像
```

**flat スタイル**（フォルダー作成なし）:

```
20260807_会議資料の送付.html   ← 本文（画像は中に埋め込み済み）
会議資料.pdf                    ← 添付は元のファイル名のまま
```

- 同じ名前が既にあるときは末尾に _2、_3 が付きます
- 暗号化メールなど変換できないものは、壊さずそのまま残します
- 開発用フォルダー（git 管理下や node_modules など）は自動で対象外になります

## いちばん簡単な導入（exe 版・推奨）

[リリースページ](https://github.com/hironori-oi/outlook-mailmanager/releases)から
`OutlookMailConverter.exe` をダウンロードし、好きな場所に置いて**ダブルクリック 1 回**。
自動起動の登録から監視開始まで全部済みます（Python のインストールも不要）。
初回に青い警告画面が出たら「詳細情報」→「実行」を押してください。

やめたいときは、同じリリースページの `StopMailConverter.cmd` をダウンロードして
ダブルクリックすれば、停止と自動起動の解除まで行われます。

## Python で導入する方法（3 手順）

1. https://github.com/hironori-oi/outlook-mailmanager を開き、
   緑の「Code」ボタン →「Download ZIP」でダウンロードして好きな場所に展開する
   （git が使える人は `git clone` でも可。置き場所は自由）
2. 移植先に Python が無ければ、Microsoft Store で「Python 3.13」を検索して
   インストールする（無料・数分）
3. 展開したフォルダー内の **`setup.cmd` をダブルクリック**する
   → 必要なライブラリの導入・サインイン時の自動起動の登録・監視の開始まで
   すべて自動で行われます

設定（config.ini）はフォルダーの場所を %USERPROFILE%（そのPCのユーザーフォルダー）で
書いてあるため、そのまま動きます。監視対象は既定で「ドキュメント」と「デスクトップ」です。

※ このリポジトリに含まれるのはツール本体だけで、メールデータは含まれません。
   動作記録（converter.log）や変換済みの記録（state.json）も各 PC のローカルにだけ作られます。

## 日常の使い方

何もしなくて大丈夫です。パソコンにサインインすると監視プログラムが自動で
バックグラウンド起動し、対象範囲のどこかに新しいメールファイルが置かれるたびに
反応します。画面には何も常駐表示されません。

## 設定を変えたいとき

`config.ini` をメモ帳で開いて編集します（各項目の説明はファイル内）。
**編集後は `start_watcher.cmd` をダブルクリック**して監視を再起動してください。
`stop_watcher.cmd` → `start_watcher.cmd` の順で実行すると確実です
（二重起動はしない仕組みなので、何度実行しても安全です）。

## 手動で動かしたいとき

- `start_watcher.cmd` … 監視プログラムを起動（すでに動いていれば何もしない）
- `stop_watcher.cmd` … 監視プログラムを停止
- 特定フォルダーにたまった分をまとめて変換:
  `python mail_converter.py --convert "フォルダーのパス"`

## うまく動かないとき

- `converter.log` に動作記録が残ります。「変換完了」「変換エラー」などを確認してください
- ドロップしても選択画面が出ないとき: 監視が止まっていた可能性があります。
  `start_watcher.cmd` をダブルクリックしてください。以前変換したことのある場所は
  起動時に自動で回収されます

## 技術メモ

- 本体: `mail_converter.py`（Python 3.13。.eml は標準ライブラリ、.msg は extract_msg、
  フォルダー監視は watchdog、選択画面は customtkinter を使用。customtkinter が
  未導入の環境では簡素な tkinter 版の画面に自動で切り替わる）
- 選択画面のタイトルバーのアイコンは初回表示時に `lantern.ico` として自動生成される
- 自動起動: スタートアップフォルダーのショートカット `OutlookMailConverter.lnk`
  （削除すれば自動起動をやめられる）
- 安全対策: 本文 HTML からスクリプト等の危険な部品を除去してから保存。
  インターネット上の画像は初期設定では表示（config.ini の remote_images で変更可）
- 変換済みの記録: `state.json`（削除すると巡回対象の全ファイルを再変換します）
- ツール自身が書き出した入れ子メール（転送メールの中身の .eml）は再変換しない
- .cmd ファイルは日本語 Windows 用に cp932 エンコード・CRLF 改行で保存してある
  （メモ帳で編集すると保持される。他のエディタでは注意）
- extract_msg は GPL-3.0 ライセンス。個人利用は問題ないが、このツールを
  外部配布する場合はライセンス確認が必要
